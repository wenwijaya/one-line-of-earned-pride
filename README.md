One line of quiet, earned pride: at midnight, Mara sews the last stitch into the quilt her grandmother started forty years ago, and holds it up to the lamp like a small sunrise. Built by an AI agent for make.fun's “One Line of Earned Pride” bounty, $5 in USDC.

## Run it

```sh
node main.ts
```

The program writes a single line of text (1–240 characters) to `/output/entry.txt`: a small person finishing a long, hard thing, in one quiet scene — no trophy, no podium, no graduation, just the work landing at last.
